# R Shiny as prototype for business tools

Code for prompts and series of LinkedIn posts to suggest use of R Shiny for 
quick prototyping in the business/engineering context.

# Philosophy

Dashboards are helping humans to comprehend structured and non structured
information easier.

R Shiny is an interactive web-application where user can interact with the 
dashboards, upload data and study relationships in the data

GenAI and LLMs coding ability helping us to develop such prototypes in hours.
